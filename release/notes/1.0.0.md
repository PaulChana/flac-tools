# FLAC Tools 1.0.0

The first release.

- Browse a FLAC library: folders, tracks and their tags, with cover thumbnails
- Edit tags on one file or many at once, with auto-detect from file and folder names
- Check folders for problems — missing tags, stray ID3 tags, covers, track numbering, playlists — and fix them
- Run the bundled clean-up tools on folders, singly or as saved chains
- Themes, accent colours, line spacing and nine languages
